## Engineering experience

My work spans software delivery and applied machine learning:

- Document search and question answering for investment research.
- Recommendation systems for fashion, food and entertainment.
- Pricing models for marketplaces.
- Language processing, document extraction and OCR evaluation.
- Sleep biosignal analysis, robotics and embedded systems.

I work across the interface, backend and model. I care about clear behaviour,
useful evaluation and carrying the work through to release.
